# Contributing

Thank you for your interest in contributing to this project.

Contributions from the community are welcome and appreciated. Whether you're reporting a bug, improving documentation, fixing an issue, or proposing a new feature, your help makes the project better.

## Before You Start

Before opening an issue or pull request, please:

* Search existing issues and pull requests to avoid duplicates.
* Read the project documentation where applicable.
* Ensure your proposed change aligns with the goals of the project.
* Follow the project's Code of Conduct.

## Ways to Contribute

You can contribute by:

* Reporting bugs
* Suggesting new features or improvements
* Improving documentation
* Fixing bugs
* Refactoring existing code
* Improving performance
* Adding tests

Not every contribution needs to be code—documentation, ideas, and constructive feedback are equally valuable.

## Development Workflow

1. Fork the repository.
2. Create a new branch for your changes.
3. Make your changes.
4. Test your changes where appropriate.
5. Write clear, descriptive commit messages.
6. Submit a pull request explaining what you've changed and why.

Keeping pull requests focused on a single change makes them easier to review.

## Coding Guidelines

When contributing:

* Follow the existing coding style and project structure.
* Keep changes as small and focused as practical.
* Update documentation when behaviour changes.
* Add or update tests where appropriate.
* Avoid unrelated formatting-only changes.

## Pull Requests

Please include:

* A clear summary of the change.
* The motivation behind it.
* References to any related issues.
* Any additional information reviewers should know.

Large features or breaking changes should ideally be discussed in an issue before significant development begins.

## Reporting Issues

Issues may be opened for:

* Bug reports
* Feature requests
* Documentation improvements
* Questions relating to the project

When reporting bugs, include as much relevant information as possible, including reproduction steps where applicable.
