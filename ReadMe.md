<h1 align="center">Doughmination Music</h1>

A music streaming server and player. Free, no-ads, no premiums, streaming at OPUS quality.

## Installation

You can install the app at the [Downloads Page](https://doughmination.me/download)

Also on the AUR:
```bash
yay -s doughmination-music
```
